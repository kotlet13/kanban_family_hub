# Reporting security issues

Please send security reports privately to **support@jivie.app**. Include the
plugin and Kanboard versions, a description and a minimal reproduction using
synthetic data. Do not open a public issue with an active exploit or private
customer data, credentials, device tokens, backups or service-account keys.

This source distribution is FamilyHub0.13.0 and is tested with Kanboard1.2.54.
Use HTTPS, protect server configuration and data outside public directories,
and validate upgrades in a separate environment with a restorable backup.
SMTP/FCM depend on the operator's own configuration. No code publication
implies automatic upgrades or hosting security maintenance.
